## Proposed architecture: UMBRA as ICARUS's scientific proving ground
ICARUS exports a frozen strategy fingerprint, immutable event prefix and feature/model request with decision_ns, available_ns, representation_id, instrument, schema version and input hash. NEXUS/AION admit only information available at decision time. UMBRA scenario compiler produces paired worlds with identical exogenous seeds but one explicit intervention (latency, liquidity withdrawal, spread, event gap, regime or model ablation). Existing court and checkpoint evaluation receive scenario manifests, adapter version and evidence. Execution simulation is separate from forecast, and synthetic results live in a separate namespace from historical and paper outcomes. MYRIAD/POLYMIND select bounded specialists, not brokerage actions. DAEDALUS plus holdout/purgedcv independently evaluate the population with predeclared metrics; a durable JANUS/PROMETHEUS-style attempt ledger records successes and failures. ICARUS consumes only reviewed read-only challenger recommendations, risk/uncertainty evidence, abstentions and regression reports. Original Pulse remains unchanged. No direct live execution interface.
