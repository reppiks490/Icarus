## Prime-number foundation

The user's successor-prime formula is correct but computationally large.
The runtime uses a mathematically equivalent efficient next-prime search,
not the literal factorial-size nested product. Its first-qualifying-event
structure generalizes to market event-time studies.

## Truth and limits

1. MATHEMATICAL PROOF: exact prime succession and determinism for the typed
   automaton language have strong mathematical guarantees.
2. OBSERVED HISTORICAL LABELS: first-passage results only use completed future
   windows and explicitly flag OHLC simultaneous-stop ambiguity and censoring.
3. SYNTHETIC EXPERIMENTS: fictional exchange messages are simulated, not
   observed Databento depth or actual broker fills.
4. EXPLORATORY STATISTICS: one held-out Brier-score improvement is NOT a
   qualified trading signal, causal evidence, or independent replication.
5. PLANNED CAPABILITIES: expansion plans never automatically run, acquire
   paid services, deploy software, or change trading strategies.

## Visual architecture

The native ICARUS OMNIGENESIS tab reads authenticated local derived snapshots
and animates a 3D-projected research galaxy. Four modes (COSMOS, LATTICE, HELIX,
RIFT) animate atmospheric particles, filaments, orbital rings, core motion,
and record-dependent nodes. The animation does not assert agent or market activity.

The mobile gateway allowlists GET /v1/omnigenesis through its existing device
authentication. This alone does not create a new native mobile screen or
provide remote access without a correctly configured gateway and client.
